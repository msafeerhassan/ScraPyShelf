# ScraPyShelf

## Coded in Python

### A basic-CLI based tool to scrap: [Website](https://books.toscrape.com/)

#### Features:
1. Number of Pages choosen by User
2. Saving Results to CSV File
3. Efficient Error Handling
4. Multiple Pages Scrapper
5. Well-structured and Clean Code
6. Simple UI

#### How to use it?
1. Simply run the .exe (execution) file for running the scrapper.
2. Enter the number of Pages to scrap (Minimum = 1 and Maximum = 50)
3. Just wait and watch :)
